# ADR 5 : pas d'agent ni de multi-agent

**Décision.** Le flux reste un enchaînement fixe.

**Raison.** Les étapes sont connues d'avance. Un agent ajouterait du coût, de la latence et une surface d'attaque, surtout avec des textes communautaires non fiables, sans rendre de service supplémentaire.

**À réévaluer** si le produit devenait un chat libre appelant plusieurs outils.
